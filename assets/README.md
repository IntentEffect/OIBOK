# Publication assets

`intent-effect-mark.svg` is the supplied Intent & Effect artwork. Its appearance on OIBOK identifies the founding steward. Brand and trademark rights are not granted by the publication licence.

`cc-by-sa.svg` is the official Creative Commons BY-SA badge. It identifies the publication licence and links to https://creativecommons.org/licenses/by-sa/4.0/. It is used in accordance with Creative Commons' badge and trademark guidance; it is not original OIBOK artwork.

The site uses an OIBOK text wordmark. No proposed OIBOK logo concept has been adopted as an official project logo.

The GitHub mark rendered in `website/layout.mjs` comes from [Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg). Its MIT copyright and permission notice is preserved in `octicons-LICENSE.txt`. It identifies the OIBOK repository on GitHub and is not original OIBOK artwork.
