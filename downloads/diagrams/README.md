# OIBOK diagrams: draft visual set 0.1

**Draft for practitioner review.** These diagrams support practical use of the Organisation Intelligence Body of Knowledge. They are working explanations, not evidence that the full OIBOK model has been validated.

Each PDF is A3 landscape. [Download all nine diagrams in one PDF](OIBOK-Diagrams-Draft-0.1-A3.pdf).

| Diagram | Purpose |
| --- | --- |
| [The OIBOK working model](overview.pdf) | Connect the six capabilities with context, organisational orientation, governance and memory. |
| [Applying OIBOK to one real problem](applying-oibok.pdf) | Follow one inquiry through investigation, work design, evaluation and retained learning. |
| [From handoff to accepted commitment](accepted-handoff.pdf) | Make acceptance, ownership and unresolved conditions explicit. |
| [People, AI and authority in one workflow](people-and-ai.pdf) | Distinguish AI assistance, human review, authority and escalation. |
| [Evaluating the change and AI contribution](evaluating-change.pdf) | Compare credible options and consider competing explanations for a result. |
| [From a lesson to lasting capability](lasting-capability.pdf) | Retain a useful change and check later use under changed conditions. |
| [A shared vocabulary for one workflow](shared-vocabulary.pdf) | Illustrate local relationships between evidence, cases, decisions, policy, roles and action. |
| [One inquiry across the OIBOK tools](connected-records.pdf) | Keep the same inquiry connected across the working records. |
| [How review effort changes the resource case](resource-comparison.pdf) | Show the fictional Wattle Supply example's sensitivity to review effort. |

The fictional cases are illustrations, not empirical findings. Pending actions and persistence checks remain pending. A local vocabulary example is not a validated OIBOK ontology.

Research source edition: OIBOK 1.0. Practical Toolkit: 0.1. The figures were prepared alongside illustrated Guide draft 0.3; the online Guide remains at its published version until that separate edition is released.
