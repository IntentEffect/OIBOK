# Source provenance

The publication contains the original chapter and register files from Project OI Body of Knowledge Release 1.0, dated 15 August 2026. The historical Project OI name and component metadata remain in those files. The release completion record promotes chapter component version 0.3 and the identified derived register versions into Release 1.0.

The `content/knowledge/` and `content/research/` source files named in `import-checksums.json` retain their original bytes. The website renders them for reading and adds navigation and release context. New overview pages are editorial introductions, not amendments to the historical research release.

The practical toolkit and A3 canvases are version 0.1, dated 22 November 2026. Their original Markdown, Word, PDF and ZIP resources are retained. The toolkit is a practice extension and does not amend the canonical research release.

`import-checksums.json` records the SHA-256 digest, byte length and original filename for every imported publication or download. These checks establish file identity, not scientific or editorial validity.

The original release ZIPs remain under `downloads/research/`. They include the full release audit trail. The current CC BY-SA 4.0 publication terms are stated in the repository licence and website licensing page; third-party references retain their own rights.
